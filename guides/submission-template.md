## How to Submit

1. Fork the repo
2. Create a new branch: `add-destination-[destination-name]`
3. Add your guide file to the `guides/` directory
4. Link your new guide from this README
5. Open a Pull Request with the `destination-request` label
6. Wait for at least 1 community review before merging

---

> **Naming convention:** `guides/[NN]-[problematic-short-desc].md`
> Examples: `guides/05-socotra-island.md`, `guides/06-north-dalmatia.md`
